# Demo assets

`01-proposal.png` and `02-result.png` are screenshots from a real run of the private Past You Sprite using its Ollama connector. The result screenshot shows the original test passing on the historical code and failing after a predefined hypothetical mutation. The proposed change was not executed.

`past-you-demo.mp4` is a short draft assembled from those still screenshots with macOS system narration and selectable captions. It is not a continuous screen recording. `captions.srt` is the matching caption file. Review the draft before sharing.
